## 📖 Overview

AI-Perception is a modular computer vision framework designed for **real-time perception** in autonomous and edge AI systems. Developed as the perception engine for **SANI (Safety and Intelligence)**, it enables intelligent scene understanding through advanced deep learning models.

The framework supports multiple perception pipelines including object detection, facial analysis, emotion recognition, pose estimation, semantic segmentation, and human activity understanding.
